# Meet Gajera Portfolio

Cinematic Next.js / Three.js data science portfolio with a procedural black-hole scene, dynamic asteroids, scroll-driven transitions, and interactive portfolio dialogs.

## Interaction updates

- Experience items open a professional modal dialog on click.
- Project planets now use the same modal dialog instead of a bottom information strip.
- Technical capability items now use the same modal dialog instead of a bottom information strip.
- Click outside a dialog, press **Esc**, or use **×** to close it.
- The 3D black-hole, asteroid, scroll, education, and contact experiences remain intact.

## Run locally

```powershell
npm install
npm run dev
```

Then open:

```text
http://localhost:3000
```
